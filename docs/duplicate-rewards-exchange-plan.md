# 既知の釣果へのポイント報酬・交換機能

更新日：2026-09-26

実装ブランチ：`feature/duplicate-rewards-exchange-impl`（最新のdevを基点）

## 壁打ちで決定した内容

- アイテムと釣り場情報の両方を開発する。
- 報酬は既存の `backend/app/data/catalog.json` の `point` を参照する。図鑑登録済みの対象を釣ることに成功した場合だけ付与する。
- 誘引ルアーは高レアリティの出現率を上げる消耗品。
- 制限時間を延長する星時計、ダメージを増やす強化リールは永久装備。購入後は釣り画面の誘引ルアーの下にあるチェックボックスで装備を切り替える。
- 釣り場は情報の開示を販売する。
- 交換価格は仮値とし、報酬値確定後の再調整をTODOコメントで明示する。
- 新しい天体・星座のカタログ追加は他メンバーが担当する。本機能は対象IDと既存のレア度で動作する。

## 初期実装の仕様

| 商品 | 所持・使用ルール | 仮効果 | 仮価格 |
|---|---|---|---:|
| 誘引ルアー | 使用を選んだキャスト開始成立時に1個消費。失敗でも消費 | common / rare / super_rare / legendary の比率に 1 / 1.5 / 2 / 3 倍 | 100 pt |
| 星時計 | 永久装備。購入後に手動で装備／解除 | 装備中は制限時間+5秒 | 120 pt |
| 強化リール | 永久装備。購入後に手動で装備／解除 | 装備中は連打・長押しダメージ1.25倍 | 100 pt |
| 銀の流れの釣り場情報 | 一度購入すれば永続開示 | 画面座標 X 70〜130、Y -20〜20 の範囲情報 | 150 pt |

- 永久装備2種とルアー、釣り場の効果は併用できる。
- 釣り場の基礎倍率はレア度順に1 / 1.3 / 1.6 / 2倍。未購入でも範囲に投入すれば適用する。
- 釣り場が重なるときはレア度ごとの最大倍率を使用。ルアーとは乗算し、倍率6を上限とする。
- 釣り場は全季節に対応。範囲の境界を含み、キャスト開始時の投入点で判定する。
- 正確な釣り場座標は購入前の商品一覧APIには含めない。購入後は交換所に座標、待機中のCanvasに範囲を表示する。
- 新種は魚拓を選んだときに登録する。逃がした新種は未収録のまま。既知は報酬と釣獲数を更新して自動リリースする。
- 連打で体力を0にした直後に自然回復して成功を取り逃す既存挙動も修正する。

## データと処理の責務

- backend：図鑑登録判定、報酬、残高・所持品の永続化、交換と消費、抽選、効果の確定。
- frontend：残高・獲得ポイント、交換所、ルアー使用選択、装備表示、釣り場案内、効果込みのミニゲーム。
- APIの試行・交換リクエストIDを保存し、同じ操作の再送には二重処理しない。SQLiteの書込トランザクションで残高・在庫更新を直列化する。
- 通信断時はオンライン処理をモックへ切り替えず、同じリクエストIDで結果を確認する。未確認操作をローカルに保存し、再読込後も再確認できる。
- モックの残高・図鑑はオンラインとは別にローカル保存。季節→レア度→対象の二段階抽選をbackendと合わせる。
- 新種を選択前にDB登録していた既存APIを、成功確定と選択確定に分離する。

## 設定ファイルとカタログ連携

- 報酬：`backend/app/data/catalog.json`。未設定の `point` は0。負数・整数以外はシード読込時に拒否する。
- モック報酬：`frontend/src/data/catalog.mock.json`。他メンバーの値と同期する。
- 商品・効果・釣り場：`backend/app/data/shop.json` と `frontend/src/data/shop.mock.json`。
- TODOコメントはJSON読込側の `backend/app/economy.py` と `frontend/src/engine/economy.ts` に配置する。
- 既存DBへ `point` 列を追加し、起動時にカタログをID単位で同期する。新IDも追加し、既存の収集記録・残高を保持する。
- 報酬値が変更されても獲得済みポイントを遡って変更しない。

## 検証

- backend：新種の選択、既知報酬、失敗、試行の期限・所有者、再送・並行リクエスト、残高不足、永久装備の重複購入、ルアー消費、釣り場境界、抽選比率、DB移行、カタログ同期。
- frontend：lint・build、デスクトップとスマートフォン幅でのブラウザ表示・操作、時間延長、連打・長押し強化、60Hz/120Hzでの効果比較、オンライン／モック保存、通信断後の再確認。
- 商品設定のbackend／モック一致も自動検証する。

## 今後の調整

報酬の `point` は他メンバーが設定する。値が揃い次第、交換までの釣り回数・成功率・ルアーの消費頻度を基準に、商品価格と倍率を調整する。実装上の仮値を最終的なゲームバランスとみなさない。
